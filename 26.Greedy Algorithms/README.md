# Fast cover on Greedy Algorithms for this tutorial

In this Section, we are going to discuss Greedy Algorithms which are almost the intro for upcoming algorithms

### What is a Greedy Algorithm?

![ScreenShot](https://github.com/7amo10/Complete-Data-Structures-and-Algorithms-tutorial/blob/main/26.Greedy%20Algorithms/assets/1.What.png)

The concept here is about building the whole solution for a problem in addition to being better for a specific situation rather than other. 

### What are examples of Greedy Algorithms?

- Insertion Sort
- Selection Sort
- Topological Sort
- Prim’s Algorithm
- Kruskal Algorithm

- Activity Selection Problem
- Coin change Problem
- Fractional Knapsack Problem
